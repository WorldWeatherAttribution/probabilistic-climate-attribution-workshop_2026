# Advanced methods for climate and health attribution Summer School

This repo will be used to share materials for the probabilistic climate attribution module of the Summer School taking place at Imperial College London during August 17th-18th 2026.

The workshop will be a mix of lectures and guided practical sessions. We will be using `python` for data processing within a `Jupyterlab` environment, and `R` for statistical modelling within a `Posit (RStudio) Cloud` environment.
